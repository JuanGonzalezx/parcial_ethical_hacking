## Uso diario

1. Abrir el cuaderno propio como documento CherryTree; guardar una copia de respaldo antes de la primera edición. Si se prefiere SQLite, usar Guardar como `.ctb` desde CherryTree y actualizar esta tabla; evitar dos copias activas.
2. Completar control/alcance y duplicar las plantillas bajo la fase correspondiente. Conservar los siete nodos PTES.
3. Registrar hipótesis, sesión, comando y resultado real; insertar captura y explicación. Guardar también el original en evidencias para facilitar el informe y respaldo.
4. Usar EV-ALIAS-NNN y SES-ALIAS-AAAAMMDD-NN. Reservar PT-NNN con integrador antes de crear hallazgo común. Los números de figura se asignan durante maquetación.
5. Al cerrar, guardar y cerrar CherryTree antes de sincronizar el archivo. Revisar índice de evidencias y estado. No editar cuadernos ajenos ni intentar combinar automáticamente XML/SQLite.
