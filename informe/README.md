# Construcción del informe

Editar `INFORME.md` conforme se revisen hallazgos. El orden de 25 apartados corresponde a p. 7 del enunciado. Las instrucciones PENDIENTE deben reemplazarse por contenido o limitaciones justificadas.

Insertar cada captura con título de figura y explicación cercana. No basta con referenciar EV o rutas: al producir el PDF las imágenes y salidas necesarias deben verse dentro. Dibujar la cadena real solo después de confirmar sus pasos. Completar figura y página final en el índice de evidencia.

La maquetación/exportación se realizará al contar con contenido real, usando un editor de documentos o generador de PDF que permita revisar todas las páginas. La exportación de CherryTree ayuda a consolidar, pero no garantiza cumplir el orden ni la calidad del informe. No hay un generador de PDF configurado todavía.
