Mirar la versión de python primero



Para python3: python3 -c ‘import pty; pty.spawn(“/bin/bash”)’
 
Para python2 en la shell de la victima: python2 -c 'import pty; pty.spawn("/bin/bash")'



Después ctrl + z: stty raw -echo; fg



Para poder usar clean y comandos: 
export TERM=xterm
export SHELL=/bin/bash
